# Random Bing Search Tabs for Microsoft Edge

This unpacked extension opens multiple Bing search tabs with randomized meaningful queries in English, Vietnamese, or both.

## Load in Edge

1. Open `edge://extensions/`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked**.
4. Select this folder:

   `C:\Users\vmtes\edge-random-search-extension`

## Use

Click the extension button, choose the number of tabs and language mode, then click **Open Searches**.

The generated search URL format is:

`https://www.bing.com/search?q=YOUR_QUERY&form=QBLH`
